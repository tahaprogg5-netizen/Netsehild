راهنمای اتصال و نرم‌افزارهای پیشنهادی

نرم‌افزار متناسب با سیستم‌عامل خود را دانلود و طبق راهنما لینک کانفیگ را وارد کنید.

اندروید (Android)

برنامه‌های توصیه شده: v2rayNG یا Streisand

  1. برنامه v2rayNG را از گوگل پلی دانلود کنید.
  2. لینک کانفیگ خود را از حساب کاربری کپی کنید.
  3. در برنامه روی آیکون + کلیک و گزینه Import Config from Clipboard را بزنید.
  4. روی دکمه اتصال کلیک کنید.

آیفون (iOS)

برنامه‌های توصیه شده: V2Box, Streisand یا Shadowrocket

  1. نرم‌افزار V2Box را از اپ استور دانلود کنید.
  2. به بخش Configs رفته و روی دکمه + ضربه بزنید.
  3. گزینه Import V2ray URL from Clipboard را انتخاب نمایید.
  4. کانفیگ را فعال کرده و اتصال را برقرار کنید.

ویندوز (Windows)

برنامه‌های توصیه شده: v2rayN یا v2rayN-Pro

  1. برنامه v2rayN را دانلود و از حالت فشرده خارج کنید.
  2. لینک کانفیگ را کپی کنید.
  3. در برنامه کلیدهای Ctrl + V را فشار دهید تا کانفیگ افزوده شود.
  4. حالت Routing را روی Set System Proxy قرار دهید.

چگونه پس از پرداخت کانفیگ خود را تحویل بگیرم؟

پس از ثبت سفارش و آپلود تصویر رسید پرداخت کارت‌به‌کارت، سفارش شما جهت بررسی ارسال می‌شود. به محض تایید توسط مدیریت، کد کانفیگ اختصاصی در بخش «حساب کاربری -> اشتراک‌های فعال» به شما نمایش داده می‌شود.

آیا امکان استفاده همزمان در چند دستگاه وجود دارد؟

بله، بر اساس تعداد کاربر مجاز ذکر شده در مشخصات هر پلن (مثلاً ۲ کاربره)، می‌توانید روی دستگاه‌های مختلف از همان کانفیگ استفاده کنید.

مدت زمان بررسی رسید پرداخت چقدر است؟
